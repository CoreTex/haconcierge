WhatsApp verbinden

Verbinde dein bestehendes WhatsApp-Konto per Pairing Code. WhatsApp muss bereits auf deinem Gerät mit dieser Nummer eingerichtet sein.

So verwendest du den Code:

  1. Öffne WhatsApp auf deinem Handy
  2. Einstellungen → Verknüpfte Geräte
  3. „Gerät verknüpfen" → „Mit Telefonnummer verknüpfen"
  4. Code eingeben

Code ist ~60 Sekunden gültig. Der Status oben aktualisiert sich automatisch.
